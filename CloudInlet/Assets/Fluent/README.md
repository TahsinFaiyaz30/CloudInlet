# Fluent icon fallbacks

The app first uses the installed Windows Shell artwork for folder, drive, lock,
media, warning, information, and desktop objects. `WindowsSystemIcons` resolves
documented stock IDs on the current OS; these Windows resources are not bundled.
Files deliberately uses the colored Microsoft document below instead of the
Shell's blank unknown-file sheet. Settings and Search controls use WinUI's native
animated visual sources. Other concepts use the bundled assets described here.

Source: [Microsoft Fluent System Icons](https://github.com/microsoft/fluentui-system-icons).
Pinned revision: [cd332ec1f90cda2fad16f86754f8da52f1e9ab30](https://github.com/microsoft/fluentui-system-icons/tree/cd332ec1f90cda2fad16f86754f8da52f1e9ab30).
License: MIT; the unmodified upstream LICENSE and NOTICE are included in this directory.
Retrieved: 2026-10-08. SVG originals retain the upstream 24 px vector geometry.

The app loads 256 px PNG renders of these vectors, generated by
`scripts/render-fluent-icons.cjs` with sharp. This avoids the WinUI
[SVG IconSourceElement rendering issue](https://github.com/microsoft/microsoft-ui-xaml/issues/10081).
The renders retain transparency and colors; no extra runtime dependency is needed.
To regenerate, make sharp 0.35.5 available to Node and run `node scripts/render-fluent-icons.cjs`.

Official color variants are byte-for-byte copies. Icons with no official color variant use the
upstream filled geometry, with only its solid fill changed from #212121 to the app tint listed
below. Those tints are CloudInlet styling, not Microsoft color variants. Assets contain no
embedded external images or executable code. UI animation is supplied separately by the app.
